margins

how to use them · markup · visual worlds

Collage = the life you’re building. Margin = the loose threads that don’t deserve a whole section — written beside the work, not inside it.

Creative uses

Same feature, six different jobs. Pick the job first — then the look.

Logistics under vision

Collage stays sacred. Errands live underneath as glowing whispers.

use B

use C

One journal line

Not a task list — a single ruled whisper under the day, like a diary caption.

kept the induction. soft day.
write the day’s line…
<div class="day-margin day-margin--journal">
  <p class="day-margin-line"
     contenteditable>
    kept the induction. soft day.
  </p>
</div>

How: Cap at 1–2 lines. Feels like captioning the collage, not managing todos.
